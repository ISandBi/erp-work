# Frontend (React + Vite)

Aplicación en React con JSX, sin TypeScript.

## Desarrollo

```bash
cd frontend
npm install
npm run dev        # http://localhost:5173 (requiere el backend en el puerto 3000)
```

## Producción

```bash
cd frontend
npm run build      # genera frontend/dist
cd ../backend
npm start          # sirve frontend/dist en http://localhost:3000
```
