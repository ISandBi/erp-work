# Incidencias técnicas

Cada incidencia es un archivo `INC-NNN-descripcion.md` con este formato:

- **Tipo:** bug | deuda técnica | seguridad | rendimiento | compatibilidad
- **Módulo afectado:**
- **Severidad:** baja | media | alta | crítica
- **Síntoma:** qué se observa
- **Pasos para reproducir:**
- **Criterio de aceptación:** qué prueba debe pasar al corregirla

Las incidencias de la sesión 1 se publican al inicio del ciclo. Las que inyecta el instructor
llegan a mitad del proyecto y se marcan con la etiqueta `inyectada`.
